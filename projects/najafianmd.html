Overview

A freelance project to rebuild the website of a plastic surgery practice. I was the only developer, so I handled architecture, development, security, accessibility, SEO, deployment and launch, working directly with the client.

What I built

  • A migration of an 81-page site off Squarespace with zero broken links. All 79 legacy URLs are preserved with 301 redirects, a sitemap and structured data (JSON-LD).
  • A Git-based admin panel (Sveltia CMS) so the client can edit content without code. Schema validation (Zod) blocks bad edits before they go live.
  • Serverless forms on Cloudflare Pages Functions, protected by Turnstile and a honeypot field, with rate limiting, email delivery through Resend and newsletter sign-up through Constant Contact.
  • A privacy-first design: patient requests are emailed and never stored, and the newsletter is explicit opt-in only.
  • Security hardening with Cloudflare Access (Zero Trust), a strict Content Security Policy using SHA-256 hashes, HSTS and security headers.
  • WCAG 2.2 AA accessibility. I audited all 81 pages with axe-core and found zero violations.
  • A two-environment workflow (staging and production) with GitHub Actions and build-time guards against indexing mistakes.
  • The production launch itself: DNS records (SPF, DKIM), custom domain and SSL, 301 forwarding, and no impact on the existing Google Workspace email.

A launch day bug

Browser autofill was filling the hidden anti-spam field in the contact form, which made the site drop real submissions. I found it on launch day and fixed it.

Tech stack

Astro, TypeScript, Cloudflare (Pages, Functions, Workers, KV, Access, Turnstile), Sveltia CMS, GitHub Actions, Resend, Constant Contact API, Zod and axe-core.
