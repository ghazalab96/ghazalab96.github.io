Overview

A full-stack application built as a second-semester university project in the Advanced Java course at FH Campus Wien. The project demonstrates layered architecture — the classic separation of concerns across presentation, business logic, and data access layers — implemented with a Java Spring Boot backend connected to a relational database, and an Angular frontend consuming RESTful API endpoints.

Architecture

The application is organized into three distinct layers, each with a single responsibility:

Presentation Layer
Angular · TypeScript · HTTP Client
↕
Business Logic Layer
Spring Boot · REST Controllers · Service classes
↕
Data Access Layer
JDBC · SQL · Repository pattern

Backend

The backend is a Spring Boot application exposing RESTful API endpoints. Business logic lives in service classes, keeping the controllers thin and the data access layer isolated. Database connectivity is handled via JDBC with plain SQL queries — no ORM — which made the data access layer transparent and helped me understand what queries were actually being executed.

  • Spring Boot: Application framework, dependency injection, and REST controller setup
  • REST API endpoints: CRUD operations tested and documented using Postman
  • JDBC: Direct database connectivity with parameterized queries to prevent SQL injection
  • SQL: Relational schema design, queries, and data modeling

Frontend

The Angular frontend consumes the backend API via Angular's HTTP Client. Components are organized around the data model, with services handling API calls and passing data down to presentational components.

What I Learned

  • Why layered architecture matters: changing the database layer didn't require touching the business logic, and vice versa
  • How Spring Boot's dependency injection works in practice, not just in theory
  • The full REST request/response cycle: routing, serialization, error handling, and status codes
  • How to use Postman to test and document an API before building the frontend
  • JDBC vs. ORM tradeoffs — writing raw SQL made the data layer clearer but more verbose
  • Connecting an Angular frontend to a Java backend for the first time
