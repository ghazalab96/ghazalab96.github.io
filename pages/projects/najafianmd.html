Overview

A freelance project to redesign and migrate a medical practice website for Dr. Najafian in Vienna. The original site was built on Squarespace — which was expensive, slow, and difficult for the client to maintain. I rebuilt it from scratch using Astro, moving 81 pages off Squarespace to a modern static stack with a headless CMS, Cloudflare security, and full WCAG 2.2 AA accessibility compliance.

The Problem

The existing Squarespace site had three core issues: monthly subscription costs that added up over time, performance problems on mobile, and no straightforward way for the clinic staff to update content without touching code or paying for Squarespace's editor tier. The client needed something they could own outright and update themselves.

Technical Stack

  • Astro: Static site generator that outputs zero-JS HTML by default, resulting in fast load times and excellent Core Web Vitals scores
  • TypeScript: Used throughout for type safety in components, content schemas, and utility functions
  • Sveltia CMS: Git-based headless CMS that lets the client edit content directly from a browser UI without touching code — changes commit to the repo and trigger a deploy automatically
  • Cloudflare: DNS, CDN, DDoS protection, and Web Application Firewall rules configured for a healthcare context
  • Serverless forms: Contact and appointment request forms handled via serverless functions — no backend server required

Accessibility

Medical websites have a wide audience including elderly users and people with disabilities. I implemented WCAG 2.2 AA compliance throughout: proper heading hierarchy, sufficient color contrast, keyboard-navigable components, skip-to-content links, and meaningful alt text on all images. The site passes automated accessibility audits and was manually tested with screen readers.

Migration

Migrating 81 pages meant mapping content from Squarespace's export format to Astro's content collections, preserving URL structure for SEO, and setting up 301 redirects for pages that changed paths. The migration was done with zero downtime using a staged Cloudflare deployment.

What I Learned

  • How to scope and deliver a freelance project end-to-end, from initial brief to production handoff
  • Astro's content collections and island architecture for content-heavy sites
  • Cloudflare configuration for a security-conscious deployment context
  • The practical tradeoffs between self-hosted CMS options for non-technical clients
  • WCAG 2.2 accessibility standards and how to audit against them systematically
